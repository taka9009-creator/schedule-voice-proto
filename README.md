# 喋るスケジュール (Voice Scheduler) - SOP エグゼクティブ版

> **コンセプト**: 「AIを活用したスケジュール管理自動化プロセス標準運用手順書 (SOP)」準拠。
> 時間の「記録」ではなく「統治」を行い、ダブルブッキングを完全自動回避するコグニティブ・AI秘書。

ViteやNode.jsなどのビルドツールを使わず、純粋な **HTML / CSS / JavaScript** だけで作られた、初学者にも優しく安全なWebアプリケーションです。

---

## 🏛️ SOP（標準運用手順書）に準拠した3大機能

### 1. ダブルブッキング自動検知 ＆ 競合解消プロトコル (Read-before-Write)
書き込む前にAIが既存予定を先行スキャン。1分でも重複があれば即座に競合アラートを発し、3つの論理的選択肢を提示します：
* **① [AI推奨] 既存を維持し、別の空き時間を採用**: 既存予定の終了後に自動スライド。
* **② 既存をキャンセルして上書き**: 競合する古い予定を削除して新しい予定を登録。
* **③ 重複のまま登録（後で調整）**: 警告バッジ付きで両方保存。

### 2. 戦略的タスク管理（第2領域：未来への投資時間）の自動確保
* *「来週の空いている時間で、事業計画のために1時間の枠を2つ確保して」* といった抽象的指示をAIが理解。
* **ビジネスゴールデンタイム厳守（平日10〜18時）**、**4タスク・ルール（1日4タスクまで）**、**週分散配置** に従い、最適な2枠を自動ブロッキングします。

### 3. AIとのスマートな対話ラリー（情報不足の確認）
時間や詳細が不足している場合（例:「明日の午後、面談」）、AIが「何時までですか？」と穏やかに聞き返し、ワンタップで確定できる対話UIを搭載。

## 🚀 使い方とデモシナリオ

1. ブラウザで `index.html` を開きます。
2. 画面上の **「SOP標準操作ステップ・発話サンプル」** をクリックするか、マイクで話しかけます：
   * 🗣️ **「10月10日の13時から15時、ヤナピーとYouTube撮影の予定を入れて」**（SOP標準操作）
   * 💎 **「来週の空き時間で事業計画の枠を2つ確保して」**（第2領域タスク確保）
   * ⚠️ **「10月10日 14:00〜 緊急役員会議」**（ヤナピーとの予定と重複し、競合解消プロトコルが発動！）
